# SimLightIN: Simulador de Gestión Eléctrica

[Newsletter IA-ismo en LinkedIn](https://www.linkedin.com/newsletters/ia-ismo-7013065703138177024)

---

## ¿Qué es este proyecto?

Este simulador interactivo forma parte de la iniciativa educativa de la newsletter **IA-ismo** y está diseñado para ayudar a comprender, de manera visual y práctica, los retos de la gestión energética en una red eléctrica moderna.

El objetivo es transmitir, de forma sencilla y gamificada, cómo múltiples factores (fuentes de energía, consumidores, eventos aleatorios, reservas, clima, etc.) afectan el equilibrio de una red eléctrica. El proyecto está pensado tanto para divulgación como para formación y concienciación.

---

## ¿Cómo funciona?

- **Panel central SCADA**: Visualiza la frecuencia de la red en tiempo real. El objetivo es mantener la frecuencia dentro del rango seguro (49.8 Hz a 50.2 Hz).
- **Fuentes de energía**: Activa/desactiva fuentes (solar, eólica, hidro, gas, nuclear) y reservas (primaria, secundaria, terciaria) para ajustar la producción.
- **Consumidores**: Conecta o desconecta consumidores (casas, pueblos, ciudades) para aumentar o reducir la demanda.
- **Eventos aleatorios**: El simulador genera eventos inesperados (olas de calor, averías, festivales, etc.) que afectan la producción o el consumo y exigen reacción.
- **Mensajes dinámicos y señales visuales**: El sistema guía al usuario con mensajes y emojis para indicar dónde debe actuar (por ejemplo, conectar consumidores o ajustar energía).
- **Restricciones realistas**: Solo se pueden añadir consumidores cuando el sistema está equilibrado. Algunas reservas pueden quedar bloqueadas por eventos.

---

## ¿Qué aprenderás?

- El equilibrio entre producción y consumo es fundamental para la estabilidad de la red.
- Los eventos inesperados y el clima influyen en la gestión energética.
- La importancia de las reservas y la flexibilidad del sistema.
- La toma de decisiones rápidas y el impacto de cada acción en la estabilidad.

---

## ¿Cómo usar el simulador?

1. **Conecta consumidores** cuando el sistema esté en verde (estable).
2. **Activa/desactiva fuentes** para ajustar la producción según la demanda y los eventos.
3. **Responde a los eventos aleatorios** siguiendo las instrucciones y señales visuales.
4. **Mantén la red estable** el mayor tiempo posible.
